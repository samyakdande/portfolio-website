## ✦ CORE ARCHITECTURE & PHILOSOPHY

This project was built following a strict "Cinematic Brutalism" mental model:

1. **Non-Euclidean Layouts:** Uses expandable GSAP-driven accordions, infinite scrolling marquees, and dynamic flexing grids instead of standard row/col layouts.
2. **Cinematic Micro-interactions:** UI text doesn't just fade in—it decodes in real-time (`ScrambleText`). Pop-ups aren't flat—they are 3D HUDs with laser scanners, CRT scanline overlays, and live-generated hex data.
3. **Z-Depth Parallax:** Extreme use of `perspective` and `translateZ` physics. The environment physically tilts on the X/Y axes based on mouse tracking, creating heavy visual depth.
4. **Architectural Brutalism:** Strictly monochrome (Black, White, Stone). Heavy typography (`font-black`, `tracking-tighter`). Unapologetically stark contrasts.

## ✦ KEY COMPONENTS

- **The Monolith Hero:** A heavily atmospheric hero section with stereoscopic RGB text glitches and a persistent flickering grid background.
- **The Neural Node (Skills):** A kinetic accordion system. Hovering triggers a violent background inversion, while active panels spawn a 3D Parallax HUD. Features live text scrambling and automated SVG tech-logo mapping.
- **Story Scroll (Experience/Projects):** Smooth, narrative-driven GSAP pinning that walks the user through professional experience like a movie sequence.

## ✦ LOCAL DEPLOYMENT

To run the system architecture locally:

```bash
# Clone the repository
git clone https://github.com/samyakdande/Portfolio-website.git

# Navigate into the directory
cd Portfolio-website

# Install dependencies (using pnpm for strict dependency resolution)
pnpm install

# Initialize the local server
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) to view the terminal interface.
